# Research

## Source Policy

- The Researcher uses parallel local-and-network search by default.
- Local sources include repo docs, project context, paper notes, CUDA optimization skills, source code, tracked third-party material, and allowed local reference material.
- Network sources should be searched at the same time as local references when handling ordinary research requests.
- Network search does not require per-request operator approval.

## Reporting

- Research summaries should say whether each important idea came from local source material, network-derived material, or both.
- Network-derived ideas should include enough source attribution for the Planner, Coder, or Synthesizer to judge relevance.
- Research summaries should separate reusable optimization patterns from speculative ideas.

## Request Semantics

- Default research requests use parallel local-and-network behavior.
- A sender may explicitly request local-only research when network access would be distracting, expensive, or inappropriate for that cycle.
- A sender may explicitly request network-only research when local material is irrelevant or already exhausted.
