# Harness

## Purpose

This generated directory provides loop-local validation, lookup, rendering, state, record, and control commands derived from the generated execplan contracts.

## Contents

- `commands.toml`: generated command registry.
- `dependency-posture.toml`: Python dependency posture for the generated harness.
- `bin/`: executable command wrapper.
- `schemas/`: harness-owned JSON schemas.
- `src/`: harness implementation source.
