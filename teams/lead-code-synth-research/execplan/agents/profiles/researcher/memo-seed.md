# Researcher Memo Seed

- Default source policy is parallel local-and-network search.
- Local sources include repo docs, paper notes, CUDA skills, source code, tracked third-party material, and allowed local references.
- Network search does not require per-request operator approval when source scope is `local-and-network`.
- Research summaries must include source scope, attribution, reusable patterns, speculative ideas, applicability notes, and risks.
