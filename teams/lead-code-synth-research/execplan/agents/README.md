# Agent Bindings

## Purpose

This generated directory binds stable loop participants to concrete planned Houmao agent profiles, generated skills, memo seeds, workspace policy refs, launch posture, and notifier prompts.

## Contents

- `bindings.toml`: participant-to-agent binding registry.
- `profiles/`: generated planned profile configs, definitions, and memo seeds.
- `notifier-prompts/`: generated mail notifier prompt text for mail-driven managed agents.
