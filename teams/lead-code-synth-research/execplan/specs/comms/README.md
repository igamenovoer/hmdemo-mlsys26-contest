# Communication Specs

## Purpose

This generated directory defines schema-typed mail families, payload schemas, Markdown renderers, notifier trigger expectations, and communication overview material.

## Contents

- `comms-overview.md`: readable communication, dispatch, reply, and fallback contract.
- `templates.toml`: registry mapping template names to schema ids, schemas, renderers, and trigger expectations.
- `notifier-prompts.toml`: participant-level notifier prompt and tick posture contract.
- `schemas/`: JSON schemas for structured mail payloads.
- `renderers/`: Jinja2 Markdown renderers for structured mail.
